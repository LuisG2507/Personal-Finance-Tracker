# Personal-Finance-Tracker

# What it does?
- Reads from a CSV and formats the data to show the total income, total expenses, net  saving, and groups spending and income by category.
- In addition, it outputs three graphs that visualize the data from the CSV.

# Why I built it?
- I built this to put into effect python skills learned from the classroom using common tools, and to also better visualize my spending

# What I learned.
- Learned how to organize data from a spreadsheet using Pandas
- Using the organized data to create charts and graphs using Matplotlib

# Technologies used
- Python
- Pandas
- Matplotlib

# How to use it
- Input a csv with the following format: Date, Description, Category, Amount, Type
- Expenses are started with a minus(-)
